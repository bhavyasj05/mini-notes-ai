# Mini Notes AI

Mini Notes AI is a lightweight project for building an AI-assisted note-taking experience. The goal is to make it easier to capture short notes, organize ideas, and use AI features to summarize or refine content.

## Features

- Create and manage quick notes
- Keep notes simple, focused, and easy to review
- Add AI-powered help for summarizing, improving, or extracting key points from notes
- Use the project as a base for a personal productivity or study assistant

## Getting Started

Clone the repository:

```bash
git clone https://github.com/bhavyasj05/mini-notes-ai.git
cd mini-notes-ai
```

Install the project dependencies according to the framework used in the source code.

For example, if this is a Node.js project:

```bash
npm install
npm run dev
```

If this is a Python project:

```bash
pip install -r requirements.txt
python app.py
```

Update this section once the final tech stack and run commands are confirmed.

## Environment Variables

If the project uses an AI API, create an environment file such as `.env` and add the required keys.

```env
AI_API_KEY=your_api_key_here
```

Do not commit real API keys or secrets to GitHub.
